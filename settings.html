Paramètres

Données de démonstration

Ajoute à Firestore quelques catégories, concours et questions de démonstration, rattachés au compte organisateur de votre choix. Les comptes eux-mêmes (admin, organisateur, participant) doivent d'abord être créés via la page d'inscription — voir README.md pour la procédure complète. Optionnel : sélectionnez également un participant pour générer un résultat d'exemple (utile pour tester le classement).

Exporter les données

Exporte l'intégralité des collections Firestore (users, categories, competitions, questions, participations, answers, results) dans un fichier JSON, pour archivage ou transfert vers un autre projet Firebase.

Importer des données

Sélectionnez un fichier JSON précédemment exporté depuis EduContest pour restaurer des données dans Firestore. Chaque document est réécrit avec le même id : un document déjà existant portant le même identifiant sera écrasé (pas de doublon) ; les documents non présents dans le fichier restent inchangés.

À propos de la plateforme
  • Base de données : Cloud Firestore (partagée entre tous les appareils)
  • Authentification : Firebase Authentication (Email/Password)
  • Technologies : HTML5, CSS3, Bootstrap 5, JavaScript vanilla
  • Voir firestore.rules pour les règles de sécurité appliquées côté serveur Firebase.
